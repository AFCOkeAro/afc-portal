AFC Design System

One token layer and one component layer for every Apostolic Faith Church surface — the global site, the West & Central Africa council, the campus and youth departments, and the Church Portal. Every value below is either measured from production AFC and WECA stylesheets or derived from a measured value to pass a WCAG 2.2 threshold.

02 · Colour

Cool ink, reserved gold

The AFC interface is near-black indigo on cool paper — #090b19 on #f3f6fc in production, 116 and 73 uses respectively. Gold appears zero times in the production stylesheet: it lives only in the logo. That is why gold is a brand-seal token here and never a UI surface.

04 · Space, shape, motion

Measured behaviour, not taste

Production is pill-dominant: 35 uses of border-radius:100px against 18 of 1px. Pills mark what is interactive; containers stay near-square. Every transition uses one curve — cubic-bezier(.25,.46,.45,.94) at 400ms, 58 times in production.

Buttons and chips take --afc-radius-pill. Cards, panels and fields take md or xs. Never mix within one component.

Motion

feedback 100ms fast 120ms base 240ms slow 400ms

Direct manipulation responds inside 100ms (Doherty). Everything above that is deliberate motion. prefers-reduced-motion: reduce collapses all durations to 0.01ms and keeps every state change instantaneous rather than removing it.

05 · Buttons

Pill, uppercase, tracked

Built from the measured production rule: pill radius, letter-spacing:3px, uppercase, 11px Inter, 16×28px padding. Minimum hit target is --afc-control-min — 44px in the default density.

The loading state swaps the label for a spinner inside the same box, so nothing reflows. Focus every button to see the two-ring focus stack — it is visible on light and dark without depending on a single colour's contrast.

On an explicit dark island

06 · Forms

One column, validate inline

Single-column layout, label above, help and error below the control. Errors name the problem in words and add a glyph and a heavier left rule, so the state survives colour-blindness and greyscale printing. Nothing blocks submission to report a problem.

10 · Overlay

Confirm before destroying

Destructive actions always confirm, and the confirm dialog puts the safe choice first and makes it visually dominant. The dialog is a real focus trap with role="dialog" and aria-modal; on phones it becomes a bottom sheet within thumb reach.

11 · Accessibility

Built in, not bolted on

Text contrast
Every semantic pair ≥ 4.5:1, asserted in CI by tools/contrast-check.mjs.
Non-text
Borders, icons and focus rings ≥ 3:1 (WCAG 1.4.11).
Target size
44px default density, 32px compact. WCAG 2.5.8 floor is 24px.
Focus
Two-ring stack, light inner + ink outer, on every interactive atom.
Colour independence
Status always pairs colour with a word and a glyph.
Motion
prefers-reduced-motion honoured globally; motion is never the only signal.
Zoom & reflow
Layout reflows to 320px; tables collapse to cards below 48rem.
Forced colours
System colours are not fought; borders map to CanvasText.

Contrast is computed, not asserted. Run node design-system/tools/contrast-check.mjs — it exits non-zero on any failing pair, so an inaccessible token cannot merge.
